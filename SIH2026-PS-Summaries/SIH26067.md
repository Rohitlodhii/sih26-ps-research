# SIH26067 — Web-Based Interactive 3D Ocean Data Visualization Platform (INCOIS)

- **Organization:** Ministry of Earth Sciences (MoES/INCOIS)
- **Category:** Software | **Theme:** Disaster Management
- **Difficulty Score:** 6.5/10

## What the PS is about
INCOIS archives huge ocean model outputs (3D temperature/salinity/currents/chlorophyll in NetCDF) plus Argo float and glider observations — but no web-based tool co-visualizes them in 3D; operational oceanographers juggle desktop software.

## What to build
A browser-native 3D visualization system:
- Volumetric rendering of model fields across the water column: depth slices, isosurfaces, time animation (WebGL/Three.js/Cesium.js)
- Overlay of Argo/glider/CTD profiles with clickable depth-vs-variable charts
- Parsers for NetCDF (xarray backend) and delimited text; modular ingestion
- Custom colorbars, variable selectors, vertical exaggeration slider
- REST/OPeNDAP backend, OGC/CF-convention standards, plugin architecture for new sensors (ADCP, HF-radar, moorings)

## Key challenges
Browser-side 3D volumetric rendering performance, NetCDF parsing/serving, geospatially accurate overlays.

## Why this difficulty
Serious data-viz engineering, but well-specified with modern tooling; no ML needed.
