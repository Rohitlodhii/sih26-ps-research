# SIH26073 — SkyGuard AI: Anomaly Detection for Automatic Weather Station Sensors (T/P/RH)

- **Organization:** Ministry of Earth Sciences (MoES)
- **Category:** Software | **Theme:** Disaster Management
- **Difficulty Score:** 6/10

## What the PS is about
AWS networks stream temperature/pressure/humidity that gets corrupted by sensor faults, frozen values, drift and comm failures. Threshold-based QC misses complex anomalies, polluting forecasts.

## What to build
A real-time AI anomaly-detection system that:
- Detects sensor faults, spikes, frozen values and communication errors using only T, P, RH streams
- Learns normal temporal/seasonal patterns and multivariate physical consistency across the three parameters
- Outputs alerts, severity + confidence scores, explainable root-cause classification (SHAP/LIME preferred), sensor-health status and optional corrected/imputed values
- Predicts sensor degradation for maintenance; optionally Edge AI on ESP32
- Judged on anomaly-injected data (accuracy 20%, innovation 25%, real-time 15%, etc.)

## Key challenges
Distinguishing genuine weather events from sensor faults, explainability, energy-efficient edge deployment.

## Why this difficulty
A focused time-series anomaly problem with clear evaluation — well-scoped for ML teams; edge deployment is a nice differentiator.
