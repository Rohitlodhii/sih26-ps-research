# SIH26053 — Adaptive Variable-Resolution 2.5D LiDAR Mapping for Dynamic Environment Perception (DRDO)

- **Organization:** DRDO
- **Category:** Software | **Theme:** Smart Vehicles
- **Difficulty Score:** 8/10

## What the PS is about
Raw 3D LiDAR is computationally crushing; 2D occupancy grids lose height info (curbs, potholes, overhangs). A "foveated" map — dense near the sensor, coarse far away — balances precision and performance.

## What to build
A deep-learning pipeline turning raw point clouds into a variable-resolution 2.5D semantic elevation grid:
1. Terrain analysis: drivable vs non-drivable segmentation
2. Object detection: static obstacles (walls, poles) and dynamic agents (pedestrians, vehicles)
3. Adaptive spatial representation: e.g., 5 cm cells within 10 m growing to 50 cm cells at 100 m, with a data structure avoiding alignment errors in 3D→2.5D projection
- Suggested models: PointNet++ or sparse convNets
- Real-time visualization dashboard + metrics (latency/FPS, classification accuracy vs distance, memory savings vs uniform grid)

## Key challenges
Point-cloud deep learning, the custom variable-resolution projection data structure, real-time performance.

## Why this difficulty
Specialized 3D perception research-engineering; datasets exist (KITTI, SemanticKITTI) but the foveated-grid engine is genuinely novel work.
