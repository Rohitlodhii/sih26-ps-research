# SIH26028 — Dynamic Forecast of Expected Time of Arrival (ETA) for Coaching Trains

- **Organization:** Ministry of Railways
- **Category:** Software | **Theme:** Smart Automation
- **Difficulty Score:** 6/10

## What the PS is about
Train ETAs today use static schedules + current delay + built-in recovery time, ignoring speed restrictions, congestion, signal halts, weather and historical patterns — degrading passenger info, platform allocation, crew scheduling and feeder planning.

## What to build
A real-time, data-driven ETA prediction system that:
- Ingests live GPS location, signal aspects, sectional running times, weather, historical delay patterns, downstream congestion
- Dynamically updates ETAs at upcoming stations as conditions change
- Uses ML/statistical forecasting that improves over time; handles temporal/spatial variability; scales to thousands of trains
- Exposes APIs for mobile apps, station displays and control-room dashboards

## Key challenges
Getting realistic train-running data (or credible simulation), building accurate multi-factor delay propagation models.

## Why this difficulty
Classic ML regression/sequence problem with a clean formulation; data access and scale handling are the main hurdles.
