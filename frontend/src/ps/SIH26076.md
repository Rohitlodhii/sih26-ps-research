# SIH26076 — Personalized Homepage for the 'Mausam' Mobile Application (IMD)

- **Organization:** Ministry of Earth Sciences (MoES/IMD)
- **Category:** Software | **Theme:** Smart Automation
- **Difficulty Score:** 4.5/10

## What the PS is about
IMD's Mausam app serves everyone the same content; different user segments need different weather presentations.

## What to build
A personalized homepage system with segment-specific widgets:
- Health users: AQI, pollen, UV index, humidity
- Fitness enthusiasts: sunrise/sunset, best running hours, wind, heat alerts
- Beachgoers/surfers: tides, wave height, sea temperature
- Travelers: saved destinations, severe-weather flight alerts, packing suggestions
- Parents: school commute conditions, rain/severe alerts
- Agriculture: soil moisture, rainfall, frost, planting guidance
- Commuters: weather + traffic/visibility integration
- Event planners: extended forecasts, rain probability, comfort index

## Key challenges
User-segmentation logic, aggregating diverse data sources (AQI, tides, traffic), clean UX.

## Why this difficulty
App-frontend + data-aggregation work with no deep modeling — approachable and demo-friendly.
