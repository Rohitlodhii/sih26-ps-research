# SIH26069 — National Weather Big Data Analytics Platform

- **Organization:** Ministry of Earth Sciences (MoES)
- **Category:** Software | **Theme:** Disaster Management
- **Difficulty Score:** 5.5/10

## What the PS is about
Weather reports flood social media (#IMD etc.) and citizen channels, but IMD has no scalable system to ingest, verify and analyze them in real time.

## What to build
A big-data analytics platform that:
- Collects real-time weather posts/info from social media, public datasets, websites, APIs and citizen reports (with metadata: time, location, GPS, media, event category)
- Stores everything in a centralized database with big-data ingestion pipelines
- Uses ML to detect fake/misleading reports, verify sources, deduplicate, and auto-categorize events (rain, thunderstorm, flood, heatwave, fog, dust storm, wind)
- Web dashboard + admin panel: date/event/location filters, verification tracking, real-time analytics

## Key challenges
Social-media API access constraints, misinformation detection quality, streaming-scale ingestion.

## Why this difficulty
Classic streaming + NLP-classification platform; scraping/API limits are the practical friction rather than modeling.
