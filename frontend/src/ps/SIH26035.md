# SIH26035 — Test Report Generator for Non-Automatic Weighing Instruments (OIML R-76)

- **Organization:** Ministry of Consumer Affairs, Food & Public Distribution
- **Category:** Software | **Theme:** Miscellaneous
- **Difficulty Score:** 4.5/10

## What the PS is about
Model approval of weighing instruments (scales, weighbridges) requires evaluation per OIML R 76 with detailed test reports currently compiled manually in spreadsheets — slow, error-prone, non-uniform.

## What to build
A desktop/web application that:
- Captures instrument specs, lab/environmental conditions, and observations for all OIML R 76 test procedures
- Auto-computes permissible errors and pass/fail compliance status; validates entered data
- Generates standardized digital test reports (PDF/Word) with auto-populated details; optional digital signatures
- Maintains a report repository, dashboards, search/retrieval, role-based access; supports future OIML revisions

## Key challenges
Reading and correctly encoding the OIML R 76 test procedures and error formulas — domain accuracy over tech complexity.

## Why this difficulty
Essentially a well-specified forms + calculation + report-generation app. Straightforward; the effort is in the metrology domain detail.
