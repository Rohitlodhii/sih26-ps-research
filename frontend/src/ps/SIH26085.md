# SIH26085 — Urban Flood Nowcasting System (Drainage + Rainfall Coupling, 0–3 h)

- **Organization:** Ministry of Earth Sciences (MoES)
- **Category:** Software | **Theme:** Disaster Management
- **Difficulty Score:** 8/10

## What the PS is about
Knowing how much rain falls doesn't tell you which streets flood — that depends on micro-topography, impervious surfaces and invisible drainage networks. Metros like Mumbai/Delhi/Chennai get caught off guard yearly.

## What to build
A street-level flood nowcasting system (0–3 h lead):
- Fuses radar rainfall nowcasts with high-res DEM (2D surface routing) and a graph model of the stormwater drain network (nodes = manholes/inlets, edges = pipes)
- Computes hydraulic capacity, predicts surcharge/blockage backflow onto specific streets/intersections
- Web GIS dashboard showing street-by-street water depth (cm) in a 0–3 h window
- API for navigation integration to suggest flood-safe routes for emergency services and commuters

## Key challenges
Hydrological modeling (2D overland flow + 1D network hydraulics), missing drain data for Indian cities, real-time computation.

## Why this difficulty
Genuine coupled hydrology + ML engineering; strong public-health/disaster relevance but heavy modeling.
