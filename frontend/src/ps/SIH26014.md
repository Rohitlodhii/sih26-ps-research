# SIH26014 — An Integrated GIS-based Digital Public Infrastructure for Land Governance ("Land Stack")

- **Organization:** Ministry of Rural Development (DoLR)
- **Category:** Software | **Theme:** Agriculture, FoodTech & Rural Development
- **Difficulty Score:** 6.5/10

## What the PS is about
Land data in India is fragmented across departments (cadastral maps, RoR, registration, taxation, utilities, master plans). DoLR's "Land Stack" — piloted in Chandigarh and Tamil Nadu (launched 31 Dec 2025) — aims to unify everything on parcel-level GIS with ULPIN as the common key, to be scaled across India. Land being a State subject means huge diversity in formats, units, languages and workflows.

## What to build
A scalable Land Stack prototype that:
- Organizes data into base layers (geo-referenced cadastral maps, parcel boundaries, ULPIN), essential layers (RoR, registration, master plans, building permissions, encumbrances, land use/zoning) and use-case layers (utilities, taxation, valuation, restriction zones)
- Uniquely identifies each parcel (ULPIN) and links all governance data to it
- Provides parcel-level GIS visualization and data exploration
- Handles state-wise diversity via a common interoperable state-level framework

## Key challenges
Designing a clean interoperable data model across wildly varying state formats; breadth of integration.

## Why this difficulty
Big-scope but standard web/GIS/DPI engineering; the hard part is data modeling and interoperability design rather than exotic tech.
