# SIH26056 — Real-Time Airfare Price Index (APIx) via Automated Web Scraping for CPI (MoSPI)

- **Organization:** MoSPI (National Statistical Office)
- **Category:** Software | **Theme:** Smart Automation
- **Difficulty Score:** 6/10

## What the PS is about
CPI airfares are collected manually from few outlets while 90%+ of tickets are sold online with 200–400% dynamic daily swings — official inflation stats miss what travellers actually pay.

## What to build
An end-to-end platform that:
- Scrapes fares from airlines (IndiGo, Air India, Air India Express, Akasa, SpiceJet) and OTAs (MakeMyTrip, Yatra, EaseMyTrip, Cleartrip, Ixigo, Goibibo) daily, handling JS rendering, anti-bot measures, rate limiting — ethically per robots.txt/ToS
- Cleans/normalizes quotes: outliers, sold-out flights, base fare vs taxes/fees
- Builds a Real-time Airfare Price Index (APIx) on a DGCA-traffic-weighted city-pair basket and multiple advance-purchase windows (T+1…T+45)
- Interactive dashboard (trends, sector heatmaps, lead-time elasticity) + API for NSO/RBI; 30 days of back-tested results against DGCA average fares

## Key challenges
Scraping resilience against anti-bot defenses (the practical crux), index methodology, back-test validation.

## Why this difficulty
Well-defined pipeline (Scrapy/Playwright + data engineering + dashboard); scraping fragility and compliance are the real work, no ML needed.
