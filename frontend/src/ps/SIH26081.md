# SIH26081 — Hybrid AI–NWP Multi-Model Forecast Blending System

- **Organization:** Ministry of Earth Sciences (MoES)
- **Category:** Software | **Theme:** Disaster Management
- **Difficulty Score:** 7/10

## What the PS is about
NWP models, ensembles and AI weather models each win in different regions/seasons/lead times. A dynamic blender should weight them adaptively instead of trusting one source.

## What to build
A blending framework that:
- Assigns adaptive weights to multiple forecast sources based on historical skill, lead time, region, season and regime
- Produces an optimized blended forecast for rainfall, temperature, wind and extreme-weather indicators
- Generates model-weight maps showing which source is more reliable where/when
- Includes automated operational workflow/dashboard; must beat individual models on skill

## Key challenges
Multi-model verification archives, weighting methodology (Bayesian model averaging / ML stacking), proven skill gains.

## Why this difficulty
Conceptually elegant ensemble-combination problem; data-heavy but well-suited to strong ML teams.
