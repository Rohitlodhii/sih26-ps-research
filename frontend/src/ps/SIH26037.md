# SIH26037 — Adaptive Path Planning & Collision Avoidance for Autonomous Vehicles on Unstructured Indian Roads (MathWorks)

- **Organization:** MathWorks
- **Category:** Software | **Theme:** Smart Vehicles
- **Difficulty Score:** 7.5/10

## What the PS is about
Autonomous driving systems assume lane markings, signage and predictable traffic — Indian roads have mixed traffic (autos, pushcarts, animals, jaywalkers), unmarked edges and irregular movement.

## What to build
A simulation-based adaptive path-planning system (MATLAB/Simulink):
- Multi-sensor perception (camera, LiDAR, radar fusion) detecting diverse road users
- Short-term motion prediction of non-lane-based, irregular agents
- Real-time collision-free path generation and replanning
- Validation across ≥5 Indian scenarios (unmarked village road, unsignalled urban intersection, highway merge with slow vehicles, dense market, cattle crossing) using RoadRunner scenes
- Deliverables: working simulation pipeline, ≥2 RoadRunner scenes, metrics (replanning latency, path smoothness, completion rate), technical report, demo video

## Key challenges
Sensor fusion, trajectory prediction, real-time replanning logic — all within the MATLAB/Simulink ecosystem.

## Why this difficulty
Heavy but simulation-only; MathWorks tooling reduces infrastructure burden, yet the perception+planning stack is a serious autonomous-driving problem.
